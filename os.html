Rules

These are code, not suggestions. Bad work gets blocked before you see it.

What it will never do

  • ✕Never invent proof. No fake stats, testimonials, case studies or guarantees. No real number means no number.
  • ✕Never use em dashes. They are an AI giveaway.
  • ✕Never use AI phrases. "Game changer", "leverage", "seamless", "in today's landscape" and 40 more are banned.
  • ✕Never use AI rhythm. Three short sentences then a long one. Stacked rhetorical questions. Repeating "it is not X, it is Y".
  • ✕Never mix clients. One job loads one client. It cannot borrow another client's data.

What it always does

  • ✓Loads real context first. Your client's voice, offer and proof before writing a word.
  • ✓Follows your golden rules. Each client's non negotiables block anything that breaks them.
  • ✓Remembers corrections. Fix it once and it stays fixed.
  • ✓Fails closed. If a check cannot pass, the work does not ship.

The 3 test for every claim

  • 1Can you picture it? Concrete, not vague.
  • 2Could it be proven false? Specific, not puffery.
  • 3Could nobody else say it? If a competitor could paste their logo on it, cut it.

When the checks run

  • →On save. Golden rules check every file.
  • →Before you see it. 17 output types checked for proof, specificity and structure.
  • →Before it sends. Anything going out is checked first.
  • →Before it starts. Empty client context blocks generic output.

D100

Finds dream clients, builds them free work, pitches it. Type /d100.

It asks 6 questions

  • 1Which engine: VSL, Challenge, or Webinar
  • 2Which niches to target
  • 3Your API keys, each tested live
  • 4Daily volume: 25, 50, 100 or 250
  • 5Your booking link, contact and real proof
  • 6Your proposal headline, written for you

Then per prospect

  • 1Qualify. Poor fit leads are skipped.
  • 2Research their real business and brand.
  • 3Pick the angle.
  • 4Build the funnel.
  • 5Publish the proposal page.
  • 6Send the email sequence.

Your dashboard

  • →Leads. Your whole pipeline.
  • →Build. Run a batch of 10 to 250 with a progress bar.
  • →Daily Volume. How many new prospects come in each day.
  • →D100 Types. Turn engines on and off.
  • →API Limits. Usage and upgrade alerts.

Install

Mac. About 10 minutes, once.

# 1 install Homebrew
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 2 turn it on (shows nothing, that is normal)
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"

# 3 install the tools
brew install git gh

# 4 log into GitHub first
gh auth login

# 5 install the Vault
curl -fsSL https://agentic-marketers.vercel.app/update | bash

Then open the AgenticMarketersVault folder in Claude Code and type /mybusiness.

Windows: skip Homebrew. Use winget install --id Git.Git -e and winget install --id GitHub.cli -e, then do steps 4 and 5 in Git Bash.
